# TimothyHeuer.com placeholder

Static, responsive placeholder website for TimothyHeuer.com.

Files:
- `index.html` — homepage, text, metadata, navigation, LinkedIn link.
- `styles.css` — typography, palette, layout, mobile responsiveness.

## Publish

Option A: GitHub Pages
1. Create a public repository on GitHub (e.g., `timothyheuer-site`).
2. Upload `index.html` and `styles.css` to its root.
3. In repository Settings > Pages, choose deploy from main branch / root.
4. Confirm the GitHub Pages preview address works.
5. Add `timothyheuer.com` under Custom domain and follow GitHub Pages' instructions for the DNS records at your domain registrar. Configure HTTPS when available.

Option B: Cloudflare Pages
1. Create a Cloudflare Pages project and deploy the two files as a static site (Git or direct upload).
2. Verify the `pages.dev` preview works.
3. Add `timothyheuer.com` as a custom domain and follow Cloudflare's nameserver/DNS steps.

Do not change DNS until the new hosted site is working and you have checked whether the existing domain hosts email or other services. Preserve existing MX, TXT and other required records.
